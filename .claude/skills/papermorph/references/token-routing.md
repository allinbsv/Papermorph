# ChatGPT / Claude：Token 使用、模型分工与成本控制

此规则适用于所有 PaperMorph 的中文和英文制作；**配音语言不改变成本纪律**。历史决策明确提出按阶段分工、脚本优先、复用证据和高风险复核。**尚未发现**用户为 PaperMorph 批准的精确每次 Token 数、月度 Token 上限或按量 API 美元预算。过往项目的金额、模型比例和预算*示例*不可自动移植为本项目授权。

## 执行前：以任务为单位做最小必要的模型路由

| 阶段 | 首选执行者/方法 | 升级条件 | 输入范围 |
| --- | --- | --- | --- |
| 资料去重、文件枚举、格式、字幕字段 | 本地脚本、可复现的代码和缓存 | 解析失败/内容不确定才用模型 | 文件路径、哈希、相关片段 |
| 事实提取、术语表、分镜初稿 | 当前已订阅 ChatGPT/Claude 可用的轻量/均衡模型 | 涉及冲突证据、歧义才用强模型 | 本段的原始出处与适用条件 |
| 创作改写、中文/英文自然表达 | 已可用模型，按章节/片段处理 | 质量差、反复修改或结构矛盾时升级 | 已核实事实、风格约束、目标语言、少量相邻上下文 |
| 工程事实、历史断言、公式和敏感发布 | 更强推理并回源；必要时跨模型独立审核 | 按风险要求，不因成本而跳过必要验证 | 完整的相关证据、目标、版本和条件 |
| 音频、动画、字幕和渲染检查 | 既有生成工具、定时数据、确定性脚本 + 人工观看 | 只有脚本无法判断的真诚感、音准、同步交人审 | 该版具体音频/画面，不加载整个项目聊天 |

只写实际调用过的模型。**不能自动路由时，不得虚构“Claude 已复核”或“ChatGPT 已独立审计”**；在现有平台分阶段执行并把另一个平台标 `NOT_RUN`。任何模型的自评都不是独立验收。语言两版共享已验证的事实和图像资产，但脚本、实际音频、时间戳和听感验收必须分别处理。

## 每次 LLM 调用的节制原则

1. **先查缓存再调用模型**：复用已审核的摘要、已加工图片与术语表。缓存键至少绑定文件/来源 ID、修订版或内容哈希、任务提示版本、输出语言和模型；前提不匹配立即失效。
2. **按需切片上下文**：只传本章节证据、邻近几拍和相关风格约束；不要每轮粘贴整本书、全部工作记录和重复的附件。先用 `rg`/脚本定位，再由模型推理。
3. **简单工序便宜或不用 LLM**：批量改名、格式验证、字词标记、数值计算和字幕结构用代码。不得为微小差异反复调用最高阶模型。
4. **风险优先升级**：关键事实冲突、版权/肖像/声音许可、工程数值、发布风险值得更强模型或独立复核。为了省 Token 不得降低验证边界。
5. **变化驱动重做**：仅当来源、脚本、时间戳或审稿反馈发生实质变化时重算对应片段；避免整本重生成。重试次数、失败原因和恢复点需记录，避免盲目循环。
6. **阶段交接摘要**：记录已验证的来源指针、目标版本、决策、未知、待办和下一步。摘要只是导航，不得代替必要的原证据。

## Token 台账与预算状态

为每个确实发生的模型调用记录以下字段（可以存 `tools/<book>/token-usage.jsonl`）：

`run_id, timestamp, stage, language, provider, model, access_mode, input_source_revision, cache_key, cache_hit, Tin, Tout, Ttotal, cost_usd, measurement_status, result_status`

- `Tin` = 实际输入 Tokens；`Tout` = 实际输出 Tokens；`Ttotal = Tin + Tout`，**只对实际有两项测量时计算**。
- 平台不暴露 Token、思考用量、真实价格或额度时，填 `UNKNOWN`；不能用字符数估算冒充计量。若估算用于规划，单独标 `ESTIMATE`。
- 订阅制 ChatGPT/Claude 的消息/使用额度不等同于按量 API 账单；不把平台实际不可见的 Token 当成费用。模型及套餐能力和限额以当前账户显示为准。
- 前期评估若要比较两模型，固定同一证据、工具、提示和时间范围；比较正确率、关键错误、质量和实际 Token/时长，不能只看速度或低单价。

## 付费操作硬门槛

默认 `existing_subscriptions_only`。OpenRouter、Claude API、OpenAI API、ElevenLabs、按量图像/视频生成、付费托管等，即使已发现 API key，**也不等于用户批准收费**。

如需新按量 API，先提出调用目的、范围、费用估算与最坏成本、上限和中止机制；得到用户对**该 scope**的明确授权后，记录 `token_policy.metered_api` 的批准来源和正数预算。运行前：

```bash
python3 SKILL/scripts/token_policy_gate.py books/<book>/style.json --mode metered-api --scope ch01-images-v1
```

只有 `AUTHORIZED_FOR_SCOPE` 才可进入该环节，并继续检查账户余额/实时预算机制是否能够真正限额；若平台无法强制停止，仍需停在 `HOLD` 并征求用户选择。门槛只核对**书面配置**，不代表远端账单已受控，不能代替平台实际用量监控。订阅内的普通工作用 `--mode subscription` 检查配置即可。

用户此前其他项目中出现过的 $60/$80、$10–20 等**示例或不同项目建议**不得视为 PaperMorph 的正式额度。本项目的具体上限维持 `UNKNOWN`，直至再次明确授权。
